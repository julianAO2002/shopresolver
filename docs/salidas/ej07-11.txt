===== Ejercicio 7 - IP directa vs nombre logico =====

Se levanta un segundo OrdersService (orders-by-ip) configurado con la IP fija http://172.29.0.2:8080
$ docker run -d --name orders-by-ip --network shopresolver_ecommerce-network -p 8082:8080 -e Inventory__BaseUrl=http://172.29.0.2:8080 shopresolver-orders-service
50f86a68fc46bd1685931ea622326f57552acdaf38cfc8e4b89b7c8995b94210

--- Con ambas configuraciones funcionando ---
$ curl -s http://localhost:8081/api/orders/inventory/P001
{"requestedUrl":"http://inventory-service:8080/api/inventory/P001","inventory":{"productId":"P001","stock":25,"server":"86ef2a49f6a5","address":"172.29.0.2"}}

$ curl -s http://localhost:8082/api/orders/inventory/P001
{"requestedUrl":"http://172.29.0.2:8080/api/inventory/P001","inventory":{"productId":"P001","stock":25,"server":"86ef2a49f6a5","address":"172.29.0.2"}}

--- Se recrea inventory-service (filler ocupa la IP liberada, como en el caso 172.18.0.5 -> 172.18.0.9) ---
$ docker compose stop inventory-service

$ docker compose rm -f inventory-service

$ docker run -d --name filler --network shopresolver_ecommerce-network alpine sleep infinity

IP vieja: 172.29.0.2  |  IP nueva: 172.29.0.5  |  filler: 172.29.0.2
